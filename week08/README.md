# СРС 8 Фитнес-трекер

## Запуск
1. Установить Node.js 22 или новее.
2. Выполнить npm install.
3. Скопировать .env.example в .env.

Запустить npm start. Адрес API http://127.0.0.1:3108.

## Проверка
Выполнить npm test. Проверено HTTP-сценариев: 15. Тест сам запускает и останавливает сервер, создаёт только учебные записи.

postman_collection.json импортируется в Postman. В переменной baseUrl установить адрес запущенного API.

Хранение в памяти. После остановки процесса записи исчезают.
