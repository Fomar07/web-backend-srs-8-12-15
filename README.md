# Web Backend СРС 8 12 15

Три самостоятельных учебных проекта по предмету Web технологии 2 Backend.

- week08: Express REST API и валидация данных.
- week12: MongoDB, Mongoose и CRUD тренировок.
- week15: JWT, роли пользователей, разграничение доступа и защита API.

В каждой папке находятся инструкции запуска, исходники, проверки и коллекция Postman. Требуется Node.js 22, для недель 12 и 15 также MongoDB. Настройки берутся из .env.example. Рабочие секреты в репозиторий не включены.

Проверки: 76 HTTP сценариев, 30 запросов Newman и 36 утверждений.
